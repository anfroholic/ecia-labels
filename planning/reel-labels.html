01 · What we're working with

A small canvas

62 × 28.9 mm is about the size of a Brother DK-11209 die-cut address label, so these sketches assume a 300 dpi, black-only thermal printer. That budget drives most of the decisions below. Measurements are in millimetres, and one printer dot is 0.0847 mm.

Label
62 × 28.9 mm

≈ 732 × 341 dots. If this is DK-11209, the printable area is only ≈ 696 × 306 dots (58.9 × 25.9 mm). The dashed magenta line shows it. Please confirm the number for your printer.

2D symbol · all 6 fields
18.3 mm square

The sample payload is 61 bytes, which needs a 32×32 ECC-200 symbol. With a 2-module quiet zone that is 36 modules. At 6 dots (exactly 20 mil) per module, the symbol is 18.3 mm. 63% of the label height.

2D symbol · without (P)
15.2 mm square

Dropping the customer part number makes the payload 47 bytes, which fits a 26×26 symbol. That saves 3 mm. Whether to keep (P) is a decision for you (see Compliance).

One Code 128 · (1P)
41.9 mm wide

145 modules at 3 dots (10 mil, minimum 9.5), plus 10X quiet zones. That is one linear barcode, not six. A row of six linear barcodes cannot fit next to the 2D symbol.

01b · The mark

The logo at label size

The rocket, ring and diamond tiles were traced to a vector from the 200 px PNG. The thinnest strokes are the tile outlines, about 3 px in a 157 px-tall mark (≈1.9% of its height). The print-craft rule of 2-dot minimum strokes means the master mark needs to be at least 8.8 mm tall. There's only room for about 5 mm on these labels.

So the labels use a label cut: the same mark with its outlines thickened by about 1 source pixel and traced again. The tile holes stay open, and strokes come out at about 2 dots at 5 mm. Below is a 1-bit preview of each version at 300 dpi, the way a thermal head would print it.

The trace is automatic. If you have the original vector (SVG, AI or Figma), a hand-drawn label cut will look better, especially the thin gaps between the ring and the rocket's exhaust.

02 · Concepts

Six directions

All six use the same sample reel: project 7KQX from run G803, 250 pcs, date code 2647, lot G803W07. The logo is the traced wafer.space mark in its label cut. Concepts D and F also borrow its diamond tiles and sparkles. Use the zoom control to check legibility at 1×. Turn on quiet zones to confirm that no decoration enters the 2D symbol's quiet zone.

03 · The product code

Eight characters, two meanings

The (1P) supplier part number is one opaque string to a scanner. To a person it says which run and which project. The label can show both without changing a single encoded byte.

Use a Crockford Base32 alphabet for the 4 project characters

Leave out letters that look like digits, so codes survive thermal print and handwriting:

0123456789ABCDEFGHIJKLMNOPQRSTUVWXYZ

32⁴ ≈ 1.05 M codes per run. There is no I, L, O or U, so 0/O and 1/I/L can't be confused, and accidental words are unlikely. If you ever need a check character, Crockford defines one (mod 37), but adding it would make the code 9 characters.

Separate the halves with weight and space, not characters

In the hero line the run is set in regular weight, followed by a small gap of letter-spacing, and the project is set in bold. The text is still exactly G8037KQX. Copy-paste, OCR and the human-readable rule all see the true value. Never print a hyphen or dot between the halves unless it is also part of the encoded data.

04 · Generative identity

Every project gets its own wafer map

A hash of the project code (FNV-1a feeding a small PRNG) lights up four dies. The left glyph in each tile is the stand-alone version used in concept D. The right one is the ring of dies around the 2D symbol in concept F. Both are deterministic: the same code always gives the same pattern, so a Python port will match this page exactly. They are for people, not scanners: someone can match a reel to a project without reading it.

05 · In context

On a 7″ reel

The label is drawn to scale on a 178 mm reel flange, placed between the hub and the windows. At this size the brand mark and the project code are what people read from a distance. Everything else is for the scanner and for close-up checks.

Show concept

Things to notice: does the label read as wafer.space at arm's length? Can a person find the project code on a shelf of reels? 62 mm wide is about the right size for a 7″ flange. A 13″ reel has room for a larger label, or two labels: a brand label on the flange and the EIGP 114 label next to it.

Reels for parts that are sensitive to moisture usually ship inside a moisture-barrier bag. The bag needs its own copy of this label on the outside, so make sure the design also works when seen through or stuck onto the bag.

06 · Print craft

Designing for 300 dots per inch, black only

On 1-bit thermal output, the difference between a polished label and a cheap one is mostly in the details below.

Snap everything to the dot grid

  • 2D module = 6 dots (20.0 mil). Fallback = 5 dots (16.7 mil, still ≥ 14.6).
  • Code 128 X = 3 dots (10.0 mil ≥ 9.5).
  • Hairlines = 2 dots (0.17 mm). A 1-dot line drops out on worn heads.
  • Render one 1-bit bitmap at exactly the printable size. Never let the driver scale it.

No greys, only texture

Dithered grey looks muddy on thermal paper. Where a design needs a "tint" (the edge dies in C and F), use hatching built from whole dots: 2-dot lines at 45° with a 7-dot pitch. Large solid black areas print well but use more heat and fade first, so keep solid bands small (B).

Type scale

G8037KQXhero · 13–15 pt
MYCHIP-QFN48value · 6–7 pt
(1T) LOT CODEcaption · 4–4.5 pt

Use a monospace face with a slashed or dotted zero for all data (JetBrains Mono, IBM Plex Mono). Space Grotesk is standing in for the brand face. Captions below about 4 pt break up on thermal paper.

Durability

Direct-thermal labels darken with heat and fade with UV over months to years. If reels sit in storage or travel through hot logistics, a thermal-transfer printer with a resin ribbon gives archival-grade black at the same 300 dpi, and the design can stay exactly the same.

Customers' scannersIs anyone on 1D-only receiving? If so, concept E or a second label.
  1. Absolute-layout renderer: done. ecia_labels/reel.py renders concept F in mm, one SVG per reel. It uses the product label's fields and the same fingerprint hash as this page.
  2. Brand assets: done. ecia_labels/brand.py holds the traced logo (master and label cut). Swap in the original vector paths when you have them.
  3. 1-bit raster output. Pillow renders at 300 dpi to the exact printable dot size with a threshold (no dithering). Send it to the printer with the brother_ql package or the vendor driver at 100% scale.
  4. Extend the self-test. Decode the final bitmap with zxing-cpp, not just the SVG, so the decoration, threshold and dot snapping are all verified.
  5. Print & grade. Print a short run, scan it with the customer's scanner model, and adjust captions and hatch density.
